# 侍戦闘アニメーション 制作基準 v0.1（第1フェーズ成果）

根拠は `06_research_report_swordsmanship_animation.md`（出典記号 S/B/P/G/A はそちらを参照）。
数値の種類: **〔資料〕**＝出典に明記 ／ **〔提案〕**＝本プロジェクトの初期値（実制作で検証・調整する）。

## 1. 技術仕様
| 項目 | 基準 |
|---|---|
| 作業フレームレート | 30 fps で作成、エンジンで 60 fps 補間〔提案〕 |
| 単位・スケール | 1 BU = 1 m、全トランスフォーム適用済み |
| キャラクター身長 | 1.60〜1.65 m〔提案、時代考証寄り〕 |
| リグ | Rigify Human（Generate 後の DEF ボーンで変形） |
| ルート | `root` ボーンは足元・原点。前進量は root に載せる（in-place 版は root を0に固定して書き出し） |
| 刀 | `prop_katana` ボーン（原点＝鍔元）。Child Of: `hand.R` / `hand.L` / `saya_socket`（左腰）を Influence で切替 |
| 鞘 | `prop_saya` ボーン（帯に固定、鞘引き用に前後スライド・回転可） |
| 手の位置 | 刀に `grip_R`（鍔から指1本分離す）・`grip_L`（柄頭いっぱい）。両拳間隔＝指2〜3本〔資料 S1/S2〕 |
| 命名 | `SAM_<カテゴリ>_<動作>_<バリエーション>`（例 `SAM_ATK_Shomen_01`, `SAM_IDLE_Chudan_Loop`） |

## 2. 基準ポーズ：中段の構え（全アニメの始点・終点）〔資料 S1/S2〕
- [ ] 両つま先は前、左右間隔は足一つ分、前後は右足踵の線上に左足つま先
- [ ] 左踵はわずかに浮く。体重は両足均等、後ろに乗らない
- [ ] 膝は曲げ過ぎず伸ばし過ぎず
- [ ] 左拳：臍（下腹部）の約一拳前、正中線上
- [ ] 右拳：鍔からわずかに離す
- [ ] 剣先：自分の喉の高さ。延長線は相手の両眼の間（居合の中段は胸の高さ）
- [ ] 背すじ上へ、肩を下げ、顎を引く。肘は突っ張らない、脇は締め過ぎない
- [ ] 待機ループ（呼吸）：胸と肩の上下 **5〜10 mm 以内**、剣先の揺れ **2〜3 cm 以内**、周期 3〜4 秒〔提案〕。**頭の高さは不変**

## 3. 斬撃の共通構造（フェーズ定義）
| フェーズ | 内容 | 必須チェック |
|---|---|---|
| ① 起こり | 骨盤が先に動く。左足が床を押し始める | 腕より先に骨盤・左足が動いている |
| ② 振りかぶり | 右足が出る／両拳が正中線上を上がる | 手の内（握り）が変わらない、肩をすくめない |
| ③ 切り返し | 頂点で止めない | 停止フレームなし（一拍子） |
| ④ 加速 | 骨盤→胸郭→肩→肘→手の内→切先 | 各部位のピークが近位→遠位の順に遅れる |
| ⑤ 斬撃（アクティブ） | 右足着床と同時に斬撃が当たる | **着床フレーム＝ヒットフレーム（±1F）**〔資料 S2/S1〕 |
| ⑥ 減速 | 手の内を緩め、肘と肩で止める。左足を引き付ける | 切先が刃筋の平面内で止まる |
| ⑦ 残心 | 剣先を相手の中心へ戻し正対・静止 | 重心が両足中間に戻る、目線は相手 |

### フレーム配分の初期値〔提案〕（30 fps）
| 用途 | ①〜③ 予備 | ④〜⑤ 加速＋アクティブ | ⑥ 減速 | ⑦ 残心 | キャンセル可能開始 |
|---|---|---|---|---|---|
| プレイヤー通常斬り | 4〜6 F | 3〜4 F | 4〜6 F | 8〜12 F | ⑥の終わり |
| プレイヤー強斬り | 8〜12 F | 3〜4 F | 6〜8 F | 10〜14 F | ①〜③はいつでも（G1: 強攻撃キャンセル） |
| 敵の初撃 | **≥ 10 F（0.33 s 以上）** ※人間の視覚反応 約0.3 s〔資料 G1〕 | 3〜4 F | 6〜8 F | 10 F | — |
| 敵の連撃2撃目以降 | 2〜4 F（予測で対処させる）〔資料 G1 の考え方〕 | 3〜4 F | 4〜6 F | — | — |
- 斬撃の「速さ」は④⑤を実速度（短く）保ち、読みやすさは①〜③と⑦の長さで作る。
- 敵の予備動作の誇張は「腕を後ろへ引く」ではなく、**剣先を上げる・腰を沈める・骨盤を引く**で行う（剣術らしさを壊さない）。

## 4. 技別の基準
### 4-1. 正面斬り（真っ向）〔資料 S1/S2〕
- [ ] 振りかぶり高さ：両腕の間から相手の面が見える位置（剣道）〜頭上（居合）
- [ ] 軌道：正中線上の一平面（Motion Path の切先が正面から見て一直線）
- [ ] 斬り抜き：剣先は膝〜腰の高さまで（素振り基準）
- [ ] 送り足：右足を出しながら振りかぶり→左足を引き付けながら斬る
- [ ] 左手中心（左拳が正中線、右手が勝ちすぎると剣先が上がる）

### 4-2. 袈裟斬り〔資料 S1/S2〕
- [ ] 斬撃面：右上→左下へ約45°（正面12時で 11時→4時〜5時）
- [ ] 刀の返し（振りかぶり頂点での回転）は**肩より上**〔意見 P2〕
- [ ] 骨盤は相手に向けたまま、胸が右→左へ回る

### 4-3. 逆袈裟斬り〔資料 S1 五本目〕
- [ ] 7時→1時の斬り上げ
- [ ] 斬り上げの終わりで右拳は右肩の上
- [ ] 左足は動かさない
- [ ] 返した時、切先は後ろ上方。水平より下げない（そのまま袈裟斬り下ろしへ繋ぐ）

### 4-4. 横斬り〔資料 S1 十一本目／S2 胴〕
- [ ] 居合の水平斬り：切先 8時→2時、床と水平、踏み込みと同時
- [ ] ゲーム用標準横斬りは**やや下向きの斜面（10〜20°）**〔提案：剣道の胴45°と水平斬りの中間〕
- [ ] 主動力は骨盤と胸郭の回旋。腕の水平振りだけにしない

### 4-5. 突き〔資料 S2/S1〕
- [ ] 両拳を内へ絞りながら両腕を伸ばす
- [ ] 踏み込み着床と突きの到達が同時
- [ ] 左拳を上げない、正中線から外さない、刀身は水平（切先を上げない）
- [ ] 突いたら直ちに中段へ戻る（突きっぱなし禁止）
- [ ] 左足の引き付けが遅れて腰が引けないこと

### 4-6. 抜付け（居合）〔資料 S1/P4〕
- [ ] 右拳は敵の顔の中心へ
- [ ] 右手（抜く）と左手（鞘引き）が**同時・逆方向**
- [ ] 鞘離れ直前に刃の向きを変える（横一文字なら刃を横へ）
- [ ] 終わり：上体は左へ約45°開き、右拳は右前方約45°、切先は相手の左こめかみの高さを斬り抜けている
- [ ] 抜き打ち（真っ向）の場合：柄頭を前に出さず体幅内で頭上へ、左肩を開く

### 4-7. 足さばき〔資料 S2〕
- [ ] すり足：足裏が床から離れすぎない（つま先が床すれすれ）
- [ ] 腰（骨盤）の上下動：歩幅1歩あたり **±1〜2 cm 以内**〔提案〕
- [ ] 送り足：進行方向側の足→もう一方を直ちに引き付ける。後ろ足の踵は着けない
- [ ] 開き足：移動後も体は相手に正対
- [ ] 踏み込み：左足母趾球で蹴る、右膝を高く上げない、右足裏全体で着床

### 4-8. 残心〔資料 S3/S2〕
- [ ] 斬撃後、剣先を相手の中心（喉）へ戻す
- [ ] 正対し、重心を両足中間へ
- [ ] 目線は相手から切らない
- [ ] 完全静止ではなく、呼吸程度の微動を残す（待機ループへ繋ぐため）

## 5. Blender 作業手順（1動作あたり）
1. **リファレンス**：本基準の該当項目＋（あれば）映像の静止フレーム。
2. **ブロッキング**（補間 Constant）：①構え ②振りかぶり頂点 ③加速中間 ④ヒット ⑤斬り抜け ⑥残心 の6ポーズ。
3. **重心チェック**：各ポーズで重心の投影（骨盤中心の床投影）が支持基底面内か確認。
4. **スプライン化**（Bezier）：加速区間は前キーのハンドルを寝かせ（イーズイン強）、ヒット直前は Vector 寄りで鋭く。減速はイーズアウト長め。
5. **Motion Paths**：`prop_katana` の切先ボーン、`hand.L`、`hand.R` を表示。刃筋が一平面か、切先＞右手＞左手の弧の大きさか確認。
6. **足の接地**：接地中は IK 足のキーを Constant、滑り 0 mm。
7. **オフセット**：近位→遠位の遅延（骨盤→胸 1〜2 F、胸→肩 1 F、肩→手 1 F、刀は手に追従）〔提案〕。
8. **二次動作**：袖・袴・下緒・髷を 2〜4 F 遅らせる〔提案〕。
9. **ループ／遷移**：最初と最後のフレームを中段基準ポーズに一致させる（ブレンドの破綻防止）。
10. **NLA で前後の動作と並べて**遷移を確認。

## 6. 受け入れ基準（レビュー時の合否）
- [ ] 頭の高さが斬撃中に 3 cm 以上上下しない（踏み込み除く）〔提案〕
- [ ] ヒットフレームと踏み込み着床のずれ ±1F 以内
- [ ] 振りかぶり頂点に停止フレームがない
- [ ] 刃筋：斬撃区間で刃の向きと切先の進行方向のずれ ≤ 15°〔提案〕
- [ ] 足の滑りなし
- [ ] 終了ポーズが中段基準ポーズと一致（各コントロール誤差 ≤ 1 cm / 2°）
- [ ] 肩のすくみ・肘の突っ張り・右手主導（剣先の跳ね上がり）がない
- [ ] 骨盤が胸より先に回り始めている

## 7. やってはいけないこと
- 腕だけで振る（骨盤・脚が動かない）
- 振りかぶりで一度止める（二拍子）
- 手首のスナップで刃筋が捩れる
- 斬った後に前へ倒れ込む／残心なしで次へ
- 映像を見ていない作品の「見た目」を推測で真似る（本基準は原理から作る）
