# 侍の服装（平服・礼装・甲冑）リファレンス — 3Dモデリング用

## A. 平服・礼装（主に江戸時代）
### 重ね着の順序（内→外）
1. **下帯(褌, fundoshi)** — 六尺褌/越中褌
2. **襦袢(juban)** — 肌着。襟（半襟）が着物の襟元から白く見える
3. **小袖 / 着物(kosode)** — 袖口の小さい着物。**左前は死装束なので必ず右前（着る人から見て右身頃が下、左身頃が上）**。紋付(montsuki)は背・両袖・両胸の5ヶ所に家紋
4. **帯(obi)** — 男性は角帯（幅 約9〜10 cm、長さ約4 m）を腰骨の位置に低く締める。貝の口結びが代表的。刀はこの帯に差す
5. **袴(hakama)** — 腰に前紐・後紐で締める。前に**5本**（外3内2）、後ろに**2本**のプリーツ（襞）。後ろ腰に台形の**腰板(koshi-ita)**。馬乗袴（股が分かれる）と行灯袴（スカート状）。裾は足首〜くるぶし。股立ち（脇の開き）
6. **肩衣(kataginu)** — 袖なしの上衣で肩を左右に水平に張る（鯨ひげ等の芯）。袴と同布で揃えると**裃(kamishimo)**＝江戸武士の正装（登城服）。長裃は袴の裾が床を引きずる長さ
7. **羽織(haori)** — 前を胸紐（羽織紐）で留める丈の短い上着。江戸後期は「羽織袴」が平常の礼装へ
- 足元: **足袋(tabi)**（親指分割、白・紺）＋ **草履(zōri)/雪駄(setta)**・**草鞋(waraji)**（旅・戦）
- 頭: **月代(sakayaki)**＋**髷(mage)**。旅・外出で**笠(kasa)**（陣笠・編笠・網代笠）
- 旅装: 打裂羽織（背割れ）、手甲、脚絆、道中合羽

### 色・紋様の傾向
- 裃は小紋柄（遠目には無地、近寄ると細かい点模様）。色は鼠・茶・紺・黒系の地味な色が基本。
- 紋は白抜き（石持ち）。直径約 3.8 cm（背紋）。

## B. 甲冑（具足）
### 時代による形式
| 形式 | 時代 | 特徴 |
|---|---|---|
| 大鎧 (ō-yoroi) | 平安〜鎌倉 | 騎射戦用。箱形の胴、大きな**大袖(ō-sode)**、栴檀板・鳩尾板、草摺4間。小札を色鮮やかな**威毛(odoshi)**で密に綴じる |
| 胴丸 (dō-maru) | 平安後期〜室町 | 右脇で引き合わせる軽装、徒歩向け、草摺8間程度 |
| 腹巻 (haramaki) | 室町 | 背中で引き合わせる |
| 当世具足 (tōsei-gusoku) | 戦国〜江戸 | 鉄板の**桶側胴**・**仏胴**・**南蛮胴**等、鉄砲対策。素懸威（粗い綴じ）、面頬・籠手・佩楯・臑当を完備。**3D侍の最も典型的な形** |

### 部位（頭→足）
| 部位 | 読み | 説明 | モデリングのポイント |
|---|---|---|---|
| 兜 | kabuto | 鉢(hachi)＝鉄板を鋲留め（星兜・筋兜）／変わり兜 | 鉢は半球＋縦の筋（矧ぎ板）。頂上に**天辺の穴(tehen)** |
| 前立 | maedate | 兜正面の飾り（鍬形・三日月・家紋） | 薄板、金箔/真鍮 |
| 錣 | shikoro | 鉢から垂れる首を守る段々の板（3〜5段） | 段ごとに別メッシュ、外へ広がる裾 |
| 吹返し | fukigaeshi | 錣の前端が外へ折り返した耳状部分 | 家紋をつけることが多い |
| 面頬 | menpō / mengu | 顔を守る面。半頬・目の下頬・総面 | 鼻は着脱式、髭・歯の造形、顎下に**垂(yodare-kake)**（喉垂） |
| 胴 | dō | 胸・腹・背を覆う | 当世具足は剛体。前後の板を蝶番で連結 |
| 袖 | sode | 肩〜上腕を覆う板の段 | 6〜7段の小札板、肩から**紐で吊る**だけ＝腕の動きで揺れる |
| 籠手 | kote | 布地の袖に鉄の板・鎖を縫い付けた腕の防具 | 腕に沿う布（ウェイト変形可）＋剛体の板（個別ボーン/板ごと100%） |
| 草摺 | kusazuri | 胴から垂れる腰回りの板（5〜7間、各5段） | 脚の動きで干渉→間を開け、各間を1ボーン |
| 佩楯 | haidate | 太ももを覆うエプロン状の防具 | 布＋小札、脚に巻く |
| 臑当 | suneate | すね当て（篠臑当など） | 縦の細板＋鎖、膝に立挙 |
| 甲懸 | kōgake | 足の甲を守る | 足袋の上 |
| 陣羽織 | jinbaori | 甲冑の上に着る袖なし羽織（大将格） | 布、背に大紋 |
| 鎧下着 | yoroi-shita | 甲冑の下に着る小袖・袴（裾をすぼめる） | 素体に密着させる |
- **小具足(kogusoku)**: 籠手・佩楯・臑当（＝三具 sangu）＋面頬など。
- **威（おどし）**: 小札板を繋ぐ組紐。毛引威（隙間なく密）／素懸威（2本ずつ間隔を空けて縦に）。色名: 紺糸威・緋威・萌黄威・白糸威・黒糸威。
- **素材**: 鉄（黒漆塗り・錆地）、練革、絹組紐、金具（銅鍍金）、鹿革（絵韋）。黒漆の艶（Coat）＋組紐の繊維感が質感の要。

## C. 3D制作のポイント
- **衣服は別オブジェクト、厚みは Solidify**。見えない内側の素体面は削除し貫通を防ぐ。
- 袴の襞は Mesh でモデリング（ループで折り目）→ Cloth は Pin（腰紐部）で固定し、裾だけ揺らす。
- 袖（着物の振り）は四角い大きな布、袖付けは肩より下がる（ドロップショルダー）。
- 衿は左右の衿が胸で V 字に交差、首の後ろは衿が少し離れる（抜かない＝男性は詰める）。
- 甲冑は**剛体パーツ＋紐の柔軟部**の構成。小札板は Array＋ Geometry Nodes で並べ、威毛（紐）はテクスチャ＋法線で表現するのが軽量。
- 時代考証を混ぜない: 大鎧に南蛮胴、裃に甲冑などの混在は避ける。
