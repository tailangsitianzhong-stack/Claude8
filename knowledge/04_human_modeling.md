# 人物モデリングのポイント（Blender）

## 0. 全体ワークフロー
1. **資料集め**: 正面・側面の三面図（同一縮尺・同一高さ揃え）、ポーズ写真、解剖図。
2. **ブロックアウト**: 大きな塊（頭・胸郭・骨盤・四肢）で比率を確定。ここで比率が崩れていると後で直せない。
3. **ベースメッシュ / スカルプト**: Voxel Remesh → Dyntopo で解剖形状。一次形状（大きな量感）→ 二次形状（筋肉群）→ 三次（シワ・毛穴）。
4. **リトポロジー**: 低ポリをスナップ（Face Project）＋ Shrinkwrap で作り直す。Quad Remesher / QuadriFlow で自動も可だが関節・顔は手で整える。
5. **UV → テクスチャ / ベイク**（高ポリ→法線マップ）。
6. **リギング → ウェイト → 変形テスト**（極端なポーズで確認）。
7. **衣装・小物**（後述の侍衣装・刀ファイルへ）。

## 1. プロポーション（頭身）
| 指標 | 目安（写実、成人男性 ~7.5〜8頭身） |
|---|---|
| 全身 | 7.5 頭（写実）/ 8 頭（理想化・ヒーロー） / 6〜7 頭（江戸期日本人風の実感） |
| 1頭目 | 頭頂→顎 |
| 2頭目 | 乳首の高さ |
| 3頭目 | へそ（肘もほぼこの高さ） |
| 4頭目 | 股（全身のほぼ中点）、手首もこの付近 |
| 膝 | 約 5.5〜6 頭目の上（地面から約2頭分） |
| 肩幅 | 男性 約2〜2.3頭、女性 約1.75〜2頭 |
| 腕を下ろした時の指先 | 太腿の中ほど |
| 両腕を広げた長さ | ≒ 身長 |
- 頭部: 目は頭頂〜顎の**中間**。目と目の間＝目一つ分。鼻底は眉〜顎の中間、口は鼻底〜顎の上1/3。耳は眉〜鼻底の高さ。
- **江戸期の参考**: 京都・伏見の江戸時代人骨研究で成人男性の推定身長 約158 cm、女性 約144 cm。侍を写実的に作るなら現代人(約171 cm)よりやや小柄・脚短め・胴長気味にすると時代感が出る（ただし地域・身分差あり）。
- Blender では身長を実寸（例 1.60 m）にし、頭高 = 身長 / 頭身 で Empty やガイド平面を置くと比率確認が楽。

## 2. 作業ポーズ
- **A ポーズ**（腕を 30〜45° 下げる、肘・膝わずかに曲げ、指軽く開く）が現在の主流。肩周りの変形がバランス良い。
- T ポーズはリグ互換性は良いが肩が下げたときに潰れやすい。
- Rigify 前提: 正面から見て脚と背骨はできるだけまっすぐ、肘と膝に少し曲げを入れる（IK の曲げ方向が決まる）。

## 3. トポロジー（部位別）
### 顔
- **目の周り・口の周りに同心円ループ**（眼輪筋・口輪筋）。
- 鼻翼から口角を回る**法令線ループ**が目のループと繋がる「マスク」型の流れ。
- ポールは頬（鼻〜目尻〜口角の間の平らな所）に置く。
- 目のループを無限に外へ広げない。骨格（眉弓・頬骨）に沿わせて終わらせる。
- 瞼は最低 3〜4 ループ（閉じた時に厚み保持）。唇の内側は口腔へ数ループ巻き込む。
### 首・肩
- 首は円筒、胸鎖乳突筋の流れを意識。
- 肩は**三角筋を囲むループ**で腕と胴を接続。脇の下（腋窩）は面を余分に持たせると腕を上げた時に伸びに耐える。
- 肩・骨盤はスキニング時の難所。トポロジーとウェイトの両方で対処。
### 胴体
- 胸筋の下縁、腹直筋、肋骨下縁に沿う流れ。背中は肩甲骨の形を**作り込みすぎない**（腕を上げた時にゴムのように伸びる）。
### 腕・脚
- 関節（肘・膝・手首・足首）は**円周ループ＋前後にサポートループ**（3本程度）で体積保持。
- 肘の内側・膝裏は密に、外側は曲げた時に伸びる分の余裕を。
### 手
- 指は 8 面程度の円柱、関節ごとに 3 ループ。指の付け根の間（水かき）は三角/ポールが避けにくい→甲側の平らな所へ。
- 親指は手のひらの面から約 45° 傾いて生えている。手のひらはわずかに凹んだカップ形。
### 足
- 草鞋/足袋を履かせるなら指は簡略化可（足袋は親指と他4指の2分割）。

## 4. よくある失敗
| 失敗 | 対処 |
|---|---|
| 関節が曲げるとペシャンコ | 関節にループ追加、Corrective Smooth、Preserve Volume（Dual Quaternion） |
| シェーディングが波打つ | 密度を均一に、ポールを平面へ、Shade Auto Smooth |
| 自動ウェイトで変形が飛ぶ | スケール適用、重複頂点マージ、非多様体除去 |
| 横から見て平たい（正面図だけで作った） | 常に斜め45°と側面で確認、胸郭は卵形、腕は前方へ傾く |
| 脚がまっすぐ過ぎる | 太腿は外→内へ傾き膝は内寄り、ふくらはぎは外側が高く内側が低い |
| 顔が「のっぺり」 | 眉弓・頬骨・顎の骨格面を意識して平面の切り替えを作る |
| ミラー中央に隙間/重なり | Mirror の Clipping・Merge を ON |

## 5. 侍キャラクター特有のポイント
- **衣服で体のシルエットが大きく変わる**: 袴は腰から裾へ台形、肩衣は肩を水平に張る。素体は衣装下で見えない所は簡略化してよいが、首・手・足・顔は精密に。
- **重ね着の順序**: 下帯(褌) → 襦袢 → 小袖(着物) → 袴 → (肩衣 or 羽織)。甲冑は鎧下着の上に小具足 → 胴 → 袖 → 兜。Blender ではレイヤーごとに別オブジェクト、Solidify で厚みを持たせ、内側の見えない面は削除して貫通を防ぐ。
- **帯・腰回りは刀を差す基準**: 打刀は左腰、帯に刃を上にして差す。帯の位置（腰骨＝骨盤上縁）に Empty を置き、刀の親とする。
- **髷（ちょんまげ）**: 月代（頭頂を剃る）＋髷。髪はカーブ or Hair Curves。剃った部分は肌のマテリアルにわずかに青み。
- **姿勢**: 武士は腰を据えた立ち姿、肩を張らずやや撫で肩、足はやや開く。正座・居合腰の検証ポーズでウェイトをテスト。
- **甲冑は剛体**: 小札板は変形させず、各段を個別ボーン（または胴ボーン）に 100% ウェイト。縅（紐）部分のみ曲がる設計にすると破綻しない。
